# X2 Blocks

**X2 Blocks** is a number-based puzzle game built around the powers of `2`.

The game is played on a **7×5 board**. The player chooses one of five columns to place the current block. Equal neighboring blocks can attract each other according to the game's internal attraction and priority system.

The current version is a **command-line game**.

---

## Game

X2 Blocks is based on powers of `2`:

```text
2 → 4 → 8 → 16 → 32 → 64 → ...
```

Equal neighboring blocks can attract each other.

Attraction is not handled as a simple merge. The game uses its own system to determine how multiple possible attractions are resolved.

The main factors in the attraction system are:

1. **Maximum Attraction**
2. **Player Choice**

As the board progresses, the numbers generated by the system gradually increase.

The system always works within a range of **six consecutive powers of 2**, while this range changes as the game progresses.

There are additional mechanics and behaviors that are best discovered through gameplay.

## Requirements

### Python

The current version requires **Python 3.x**.

Check your Python version:

```bash
python --version
```

### Dependencies

The project currently uses:

- `random`
- `os`
- `time`
- `platform`

These are all part of the Python standard library.

The project also uses **Colorama** for terminal colors.

A copy of Colorama is included directly in the project under:

```text
Lib/colorama/
```

Therefore, **no external Python package installation is required for Colorama** when using the repository as provided.

## Installation

Clone or download the repository while preserving its directory structure.

```text

├── README.md
├── main.py
```

## Running the Game

The current version uses relative paths for its files.

For this reason, run the game from the **project root directory**.

### Windows

```cmd
cd /d "path\to\X2_Blocks"
python main.py
```

For example:

```cmd
cd /d "E:\MyFile\myCode\sheet\x2_Blocks. 01\git\X2_Blocks"
python main.py
```

Do not start the program from an unrelated working directory.

## Save System

The game includes a local save system.

Save data is stored in:

```text
Lib/memory/
```

The current implementation stores information such as:

- Board state
- Score
- Upcoming numbers
- First-run documentation state

These files are generated and modified while playing.

They are intentionally **not part of the source code** and should not be committed to the repository.

The `Lib/memory/` directory itself is kept in the project so the game has the required directory structure.

## Game Commands

The current command-line version supports:

| Command | Description |
|---|---|
| `1` – `5` | Select a column |
| `sa` / `save` | Save the current game |
| `re` / `retry` | Restart the game |
| `ex` / `exit` | Exit the game |

## Project Structure

### `main.py`

The main entry point of the game.

It handles the main game flow, player input, save/load behavior, retry logic, and exit handling.

### `dataBase.py`

Contains the core game logic.

This includes:

- Board management
- Block placement
- Random number generation
- Neighbor detection
- Attraction logic
- Attraction priorities
- Block deletion
- Column movement
- Score calculation
- Board rendering
- Save-state loading

### `Lib/colorama/`

Contains the Colorama package used by the game for terminal color output.

### `Lib/memory/`

Contains runtime save data generated by the game.

These files are ignored by Git.
